# 基于PySide6的无人系统操作面板

> 无人系统基于ROS开发，由于调试阶段需要频繁修改一些常用数据，以及需要启动特定脚本、监控数据等需求，传统的启动方式需要打开终端多个手动输入指令，且修改参数需要反复打开文件和重新编译，效率低下。对此，作者提出开发一款集成化软件，通过接口接入现有的程序，通过ROS为中间件，实现集成面板交互，我们将这款软件命名为——MyOS。

## 第一代开发要求

### 什么形式？

一款基于Pyside6开发的Ubuntu下的桌面软件，一个窗口，打开程序有LOGO加载画面，主界面暂定深灰色风格，配色后期可自行修改

### 主界面功能模块

采用模块化编程，避免过于集成化，方便替换、修改特定模块，便于后续接入&删除一些功能模块，方便后续的开发与维护；代码风格通俗易懂，函数命名规范。

每个模块由单独的python文件编写，然后以一个主程序接入运行。

#### 可视化模块
显示图像画面，话题可修改；显示实时数据）

分五个模块：感知、建图、规划、控制、驱动

## 代码结构

- **main.py** 程序主入口
- **main_window.py** 整体骨架，接入所有ui模块与ui样式

**ui** 文件夹下每个Python文件作为窗口的一个模块

**config** 目前用于进行参数交互，后续上线直接接入A03代码，config将作废

**ros_bridge** 与ROS通信，主要用于监听话题

**style** 定义样式风格
